# LastingMind 2.0 — Reward System Copy
_Suggested copy for each reward flow and stage. All copy should be reviewed and approved before implementation. This doc is a starting point — not final._

_Reference: `reward_system_flows.md` for flow definitions and trigger conditions._

---

## Copy Principles

- **Legacy language, not task language.** Never say "you completed a module." Say "your family now knows…"
- **Stage-aware.** Copy shifts in tone and content as the user progresses. Early copy orients. Mid copy builds momentum. Late copy creates anticipation.
- **Never pressure.** No "before it's too late" or urgency framing. The urgency is always positive — your family wants to know you now.
- **Short.** Every screen has a headline and a maximum of two supporting lines. No paragraphs.

## Flow B — Module Complete, No Star, Star Teaser
_Module 1 complete. Module 2 is next. One module away from a star._

### Encouragement Screen

Use stage-specific variants depending on how many modules have been completed overall:

> "What you share today becomes part of what your loved ones will one day ask about."

**Mid (modules 4–8 completed overall):**
> "You're building something real. Every story adds a layer they wouldn't have otherwise."

**Late (modules 9–11 completed overall):**

> "Complete [Category] Module 2 to earn your [Category] star."

## Encouragement Screen — Stage Reference

The Encouragement Screen (Flows A and B) uses different copy depending on cumulative module progress. Use this reference to select the appropriate variant.

| Modules completed overall | Copy direction |
|---------------------------|----------------|
| 1 | Orient. This is the beginning. Make it feel significant. |
| 2–3 | Reinforce. They came back. Acknowledge the momentum. |
| 4–6 | Educate. Help them understand what they're building and for whom. |
| 7–9 | Motivate. They're in the middle — this is where people drop off. |
| 10–11 | Urgency (positive). They are close to unlocking Phase 2. |

## Things to Avoid in All Copy

- Never say "AI" — use "LastingMind" or "your LastingMind"
- Never say "completed a module" or "finished a task"
- Never use countdown or deadline language
- Never use generic praise ("Great job!", "Amazing work!") — be specific to what they did
- Never frame the value as "after you're gone" — frame it as "your family wants to know you now"
